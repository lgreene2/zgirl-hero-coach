# Z-Girl v3.3 — Institutional Portfolio & Executive Reporting Command Center

## Purpose
v3.3 adds an executive visibility layer above the existing institutional acquisition, agreement, licensing, credential, implementation, renewal, and expansion systems.

It does not replace those systems and does not create new authority. It derives portfolio truth from the authoritative v3.0–v3.2 records.

## Operating chain
Prospect → Fit Review → Proposal → Agreement → Approval → License → Implementation → Credential Capacity → Renewal → Expansion → Executive Review.

## Executive dashboard
The restricted command center at `/institutions/ops/portfolio` provides:
- institution counts by lifecycle status;
- current and expiring license counts;
- renewal-attention counts;
- seat and trainer capacity/utilization;
- active/conditional credential capacity and 90-day credential renewal exposure;
- open agreement/release workflows;
- gross and probability-weighted pipeline value;
- expansion opportunity counts;
- institution portfolio health and expansion readiness;
- a unified executive action queue.

## Executive review record
Each institution may have one executive portfolio review containing:
- health status: Unrated / Green / Watch / Risk / Critical;
- strategic priority: Normal / Growth / Renewal / Recovery / Hold;
- expansion readiness: Not Assessed / Not Ready / Watch / Ready;
- executive owner;
- institution-level executive summary;
- next executive action;
- next review date.

These fields are business, implementation, governance, capacity, and relationship assessments. They are not participant, clinical, educational, spiritual, behavioral, or safeguarding scores.

## Portfolio snapshots
An authorized operator may create a reproducible portfolio snapshot. A snapshot freezes:
- generated timestamp;
- executive summary metrics;
- current executive attention queue.

Snapshots intentionally do not copy participant data, institutional contact directories, credential assessment scores, private reflection text, case notes, diagnoses, or safeguarding narratives.

## Authority boundary
Portfolio status does not itself:
- approve an agreement;
- execute an agreement;
- activate or expand a license;
- issue or renew a credential;
- release delivery;
- mark payment received;
- override Program Quality, Privacy Governance, Agreement Authority, Commercial Authority, or Executive Release.

## Commercial positioning
v3.3 can support a premium institutional operating package combining Partner Pipeline, Agreement Workflow, License Administration, Credential Operations, Renewal Automation, Train-the-Trainer, and Executive Portfolio Reporting.
