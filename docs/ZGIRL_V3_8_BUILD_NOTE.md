# Z-Girl v3.8 Build Note

Institutional Governance Calendar, Evidence Retention & Annual Review Automation.

This release adds administrative scheduling and evidence-retention metadata only. Automation may open work windows, register existing governance evidence for review, and flag due items. It must not delete evidence, finalize or attest evidence, change operator access, issue or renew credentials, change licenses or agreements, release implementation, or make legal/regulatory compliance determinations.
