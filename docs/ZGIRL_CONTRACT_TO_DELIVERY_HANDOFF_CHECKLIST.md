# Z-Girl Contract-to-Delivery Handoff Checklist

Use after a v3.1 institutional workflow reaches Release Review.

## Release-review prerequisites
- [ ] Structured administrative evidence packet is Complete.
- [ ] Program Quality gate is Approved or formally Waived.
- [ ] Privacy Governance gate is Approved or formally Waived.
- [ ] Agreement Authority gate is Approved or formally Waived.
- [ ] Commercial Authority gate is Approved or formally Waived.
- [ ] Executive Release gate is Approved or formally Waived.
- [ ] No required gate is Rejected.
- [ ] Linked agreement/addendum/change order is Executed.
- [ ] Authoritative agreement reference is recorded.
- [ ] Requested seat/site/trainer limits are not below current usage.
- [ ] Requested profiles and credential levels are governed Z-Girl values.

## Implementation start checks
- [ ] Active license scope matches the executed agreement.
- [ ] Active sites are within site limit.
- [ ] Adult facilitator/trainer seats are within seat limit.
- [ ] Institutional Trainer seats are within trainer limit.
- [ ] Individual facilitator credentials remain independently valid for their assigned role/scope.
- [ ] Institutional staff understand that a license does not create private-reflection access.
- [ ] Family/participant notices and local safeguarding routes are ready where applicable.
- [ ] Accessibility/accommodation responsibilities are ready where applicable.

## Commercial boundary
- [ ] Payment status has not been treated as credential status.
- [ ] Payment status has not been treated as agreement execution.
- [ ] Payment status has not been treated as approval-gate completion.
- [ ] Payment status has not been treated as license activation.
- [ ] Commercial transactions are not represented as charitable/tax-deductible donations.

## Privacy boundary
Never include participant reflection text, student/youth/athlete rosters, diagnoses, counseling or therapy notes, clinical records, safeguarding narratives, clergy/spiritual-direction records, or sports-medicine records in this handoff.
