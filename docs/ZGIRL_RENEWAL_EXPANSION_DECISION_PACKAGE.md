# Z-Girl Hero Within — Renewal & Expansion Decision Package

Purpose: turn pilot evidence into a controlled business and implementation decision rather than an open-ended continuation.

Use after the Pilot Closeout Report is substantially complete.

## Decision options

Choose one primary path:

1. **STOP** — no further implementation at this time.
2. **REVISE** — correct identified issues before another cycle.
3. **REPEAT PILOT** — run another limited implementation to validate changes or gather sufficient evidence.
4. **RENEW** — continue an existing approved scope for another term.
5. **ANNUAL LICENSE** — authorize defined organizational use for a documented audience, term, facilitator scope, support level, and approved content profile.
6. **EXPAND** — add approved sites, cohorts, teams, facilitators, profiles, or implementation volume.
7. **TRAIN-THE-TRAINER READINESS** — begin a separate controlled pathway toward preparing internal facilitators/trainers.

## 8. Train-the-Trainer Readiness Gate

Train-the-Trainer should be treated as a separate premium/licensing layer, not as an automatic benefit of a pilot or annual license.

An institution is a strong candidate when:

- [ ] it has completed at least one successful implementation cycle;
- [ ] facilitators consistently preserve participant choice and privacy boundaries;
- [ ] the institution has an accountable training/quality owner;
- [ ] implementation records are maintained without private reflection surveillance;
- [ ] accessibility and safeguarding responsibilities are understood;
- [ ] version control can be maintained;
- [ ] the institution can support observation, coaching, remediation, and reauthorization;
- [ ] brand/IP restrictions are accepted;
- [ ] commercial terms for facilitator authorization can be defined.

## 9. Commercial Conversion Checklist

- [ ] Legal commercial seller / merchant-of-record requirements are satisfied.
- [ ] Customer legal name is correct.
- [ ] Commercial offer is not represented as a charitable donation.

- [ ] Agreement or term sheet reflects the actual licensed audience and term.
- [ ] No unsupported universal compliance claim appears in sales or contract materials.
- [ ] Support commitments are operationally realistic.
- [ ] Renewal / termination terms are documented.

## 10. Decision Meeting Agenda

Recommended 30–45 minute closeout / conversion meeting:

1. Reconfirm pilot purpose — 3 minutes
2. Review implementation delivery — 5 minutes
3. Review aggregate participant / facilitator experience — 8 minutes
4. Review barriers and corrective actions — 5 minutes
5. Review governance / accessibility observations — 5 minutes
6. Select stop / revise / repeat / renew / license / expand path — 5 minutes
7. Confirm scope, owner, commercial next step, and due date — 5 minutes

## 12. Scale Path

The intended product ladder is:

**Institutional Fit Review → Limited Pilot → Aggregate Evidence → Decision → Annual License → Multi-site Expansion → Train-the-Trainer → Future Credential / Certification Layer**

Each stage should earn the right to move to the next. Scale should increase authorized implementation capacity—not institutional access to private participant reflection content.
