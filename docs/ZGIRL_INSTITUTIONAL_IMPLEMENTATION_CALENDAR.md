## Recommended implementation rhythm

The calendar is organized around seven phases. Institutions may compress or extend the timing if the approved scope still preserves readiness, facilitator preparation, participant choice, accessibility, family/stakeholder communication, aggregate measurement, and closeout.

### Phase 0 — Contract / Approval Gate

Target timing: before implementation planning is finalized.

- [ ] Commercial or pilot scope confirmed.
- [ ] Procurement / legal / vendor requirements assigned.
- [ ] Local approvals identified.
- [ ] Executive sponsor and implementation owner confirmed.
- [ ] Z-Girl pathway/profile confirmed.
- [ ] Commercial payment terms documented where applicable.

Owner: __________________ Date complete: __________

### Phase 1 — Readiness

Target timing: 2–4 weeks before launch when possible.

- [ ] Complete Institutional Readiness Assessment.
- [ ] Confirm audience, setting, participant count, and schedule.
- [ ] Confirm safeguarding / emergency escalation route.
- [ ] Confirm accessibility considerations and local support owner.
- [ ] Confirm technology/device/browser access.
- [ ] Confirm whether family/guardian notice, permission, consent, assent, or other communication is required.
- [ ] Select approved aggregate measures.
- [ ] Resolve launch conditions.

### Phase 3 — Launch

Target timing: first session / first week.

- [ ] Reconfirm participant choice: pause, skip, stop, trusted-person option.
- [ ] Explain what Z-Girl is and is not.
- [ ] Explain that private reflection text is not routine institutional reporting data.
- [ ] Confirm facilitator role and local support route.
- [ ] Start approved reflection sequence.
- [ ] Record implementation attendance/availability only to the extent approved and necessary.

- [ ] No private reflection text included in closeout reporting.
- [ ] Pilot Closeout Report drafted.

## Sample 30-day planning calendar

| Timing | Milestone | Primary owner |
|---|---|---|
| Day -21 to -14 | Readiness assessment and launch conditions | Implementation owner + Z-Girl lead |
| Day -14 to -7 | Facilitator orientation, technology test, family/stakeholder communication | Facilitator lead + institution |
| Day 1 | Participant introduction and launch | Facilitator |
| Week 1 | Reflection cycle + implementation check | Facilitator |
| Week 2 | Reflection cycle + accessibility / support review | Facilitator + implementation owner |
| Week 3 | Reflection cycle + aggregate pulse measure if approved | Implementation owner |
| Week 4 | Final reflection cycle + end-of-pilot measure | Facilitator + implementation owner |
| Day 31–37 | Aggregate scorecard and closeout report | Z-Girl lead + institution |
| Day 38–45 | Decision meeting: stop / revise / renew / license / expand | Executive sponsor |

## Sample four-session calendar

| Session | Recommended implementation purpose |
|---|---|
| Session 1 | Orientation, participant choice, reflection process, first Hero Move |
| Session 2 | Strengths, support, perspective, and practical next step |
| Session 3 | Challenge response, confidence, trusted-person connection, action |
| Session 4 | Reflection on learning, future use, aggregate feedback, closeout |

The exact content should follow the approved Z-Girl pathway/profile and current canonical materials.
