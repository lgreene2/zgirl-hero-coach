# Z-Girl v3.3 Executive Portfolio Operator Runbook

## Access
Open `/institutions/ops/portfolio` and use the existing Credential Operations operator access code. The command center reuses the same HttpOnly session architecture as Credential, License, Workflow, and Partner Pipeline Operations.

## Weekly executive review
1. Review the Executive Attention Queue.
2. Resolve or assign near-term license renewals.
3. Review agreement/release workflows with near-term effective or start dates.
4. Review pipeline decisions due within 14 days.
5. Review linked credential capacity expiring within 90 days.
6. Review institutions marked Watch, Risk, or Critical.
7. Update institution executive reviews and next actions.

## Monthly portfolio review
1. Review active institutions, pilots, prospects, and paused relationships.
2. Compare gross vs probability-weighted pipeline.
3. Review seat and trainer capacity utilization.
4. Review renewal exposure and approval bottlenecks.
5. Review expansion-ready institutions and expansion/Train-the-Trainer opportunities.
6. Create an executive portfolio snapshot with a clear reporting title and preparer name.
7. Print or save the Overview as the current executive report when appropriate.

## Portfolio health guidance
- Green: relationship and delivery are operating within expected institutional parameters.
- Watch: emerging renewal, capacity, implementation, relationship, or governance attention is required.
- Risk: material institutional issue requires executive action.
- Critical: immediate executive attention is required to protect program quality, governance, relationship continuity, or authorized delivery.
- Unrated: no executive portfolio rating has been entered.

Health ratings must not be based on private participant reflection content.

## Expansion readiness
- Not Assessed: no executive expansion review completed.
- Not Ready: expansion should not proceed under current institutional conditions.
- Watch: potential exists but conditions or evidence require attention.
- Ready: institution appears operationally suitable for a governed expansion discussion.

Ready does not authorize expansion; an expansion opportunity and the existing agreement/release workflow are still required.

## Snapshot rule
Create snapshots when the portfolio is being used for a meaningful decision, board/executive reporting period, funding/licensing strategy review, or renewal/expansion review. Do not create snapshots merely to inflate reporting history.
