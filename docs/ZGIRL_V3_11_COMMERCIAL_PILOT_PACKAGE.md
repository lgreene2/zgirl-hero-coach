# Z-Girl v3.11 — Commercial Institutional Pilot Package

## Offer

**Z-Girl Institutional Pilot** is a scoped implementation engagement that lets an institution prove fit, implementation quality and renewal value before committing to a broader annual/multi-site relationship.

## Included delivery architecture

- institutional fit / readiness review
- decision-maker and implementation-owner alignment
- approved Z-Girl profile configuration
- administrator/facilitator orientation
- safety, privacy and accessibility setup
- aggregate cohort setup
- implementation calendar and launch checklist
- midpoint implementation review
- aggregate adoption/activity tracking
- provenance-labeled evidence capture
- institutional feedback and permission administration
- closeout/evidence package
- renewal and expansion recommendation

## Internal pricing architecture

Use GLS proposal records for the actual proposed/contracted amount. Z-Girl may retain a proposed implementation amount for operational planning, but that value is not the contractual source of truth.

Recommended packaging ranges for proposal strategy, subject to scope and market validation:

- **Focused Pilot:** approximately $2,500–$5,000 — one manageable cohort, standard profile, standard implementation support.
- **Institutional Pilot Plus:** approximately $5,000–$10,000 — larger cohort, more administrative/facilitator support, additional profile/configuration or evidence requirements.
- **Multi-Cohort / Multi-Site Pilot:** approximately $10,000–$25,000+ — multiple cohorts/sites, heavier implementation support, broader reporting/coordination.
- **Specialized Design Partner:** scoped after discovery for material customization, integration or specialized accessibility/content needs.

These ranges are internal commercial architecture, not a public rate card or promise. Existing founding-partner commitments and approved proposals take precedence.

## Statement-of-work structure

A proposal/SOW should identify:
1. institution and decision maker;
2. participant population/capacity;
3. approved Z-Girl profile(s);
4. implementation window;
5. facilitator/administrator responsibilities;
6. Z-Girl implementation deliverables;
7. institution-provided dependencies;
8. privacy/safety/accessibility assumptions;
9. evidence/reporting scope;
10. fee/invoice terms in GLS;
11. renewal/expansion review date;
12. IP/license/use boundaries.

## Commercial boundary

GLS remains the source of truth for:
- opportunity stage
- proposal version
- contractual amount
- executed agreement
- invoice/payment status
- recognized revenue/commercial value
- client relationship next action

Z-Girl does not mark a payment received merely because an implementation milestone is complete.

## Public commerce

The pilot does not depend on public self-service checkout. An institution may proceed through qualification, proposal, executed agreement, invoicing and onboarding using the GLS institutional sales/contracting process while public Z-Girl checkout remains separately gated.

## Expansion ladder

Pilot → evidence → annual license → additional cohorts/sites → multi-site/network license → facilitator authorization/credential pathway → complementary GLS institutional offerings.
