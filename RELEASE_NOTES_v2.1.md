# Z-Girl Open v2.1.0 Release Notes

## Multilingual 7-Day Journey

- Adds complete English, Spanish, French, Brazilian Portuguese, and German journey tracks.
- Localizes all seven titles, focus statements, reflection prompts, strength prompts, Hero Moves, affirmations, controls, safety wording, and saved-entry downloads.
- Keeps user entries local to the browser and preserves progress when the language changes.
- Uses a matching natural device voice for each language when one is available.
- Never autoplays journey audio; the user must choose **Listen to this day**.
- Preserves the v2.0.2 AI Coach voice, speed, pitch, per-language voice preference, and sound-cues-off settings.

## Transcript Match

- Builds the visible transcript, downloaded transcript, and spoken device-voice script from one shared source.
- Includes the focus, all three prompts, affirmation, safety boundary, and permission to pause or stop.
- Makes every transcript available even when the device has no matching spoken voice.

## Install and Update Experience

- Registers the existing service worker from the application shell.
- Adds browser- and device-specific installation instructions when a native install prompt is unavailable.
- Adds manifest identity, app shortcuts, categories, language, and orientation metadata.
- Reopens previously visited pages from cache when offline; AI replies continue to require a connection.
- Shows installed users an update notice and lets them choose when to activate a new version.

## Release Boundary

- The multilingual public experience uses matching device voices.
- Translated studio-recorded audio remains internal until all seven sessions in each language pass native-language, transcript, pronunciation, cultural, safety, and final promotion review.
